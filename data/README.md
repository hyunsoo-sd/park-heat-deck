# 데이터 수집·분석 로그

## 이번 배포본

이 덱은 공개 자료와 논문을 AI가 요약·구조화한 **근거 합성 프로토타입**입니다. 부산의 특정 공원에서 계산한 새 실측값을 제시하지 않습니다.

| 단계 | 입력 | 산출 |
| --- | --- | --- |
| 수집 | 부산시 공원 자료실, 공공데이터포털, USGS Landsat, 오픈액세스 논문 | `library.md`의 출처 목록 |
| 분석 | 논문의 표본 범위·측정 단위·한계를 구조화 | `evidence.json` |
| 시각화 | 근거 합성값과 부산 분석 설계를 분리 | 슬라이드 3–5 |

## 실제 부산 분석을 위한 다음 실행

1. 부산시 공원 공간 경계(폴리곤)를 확보한다.
2. 여름철 구름 없는 Landsat Collection 2 Level-2 장면을 선택한다.
3. ST_B10을 °C로 변환하고, 공원별 동심 버퍼의 평균·중앙값·표본 수를 계산한다.
4. NDVI, 불투수면, 해발고도, 해안/수면 인접성을 함께 기록한다.
5. 결과값·코드·메타데이터를 함께 버전 관리한다.

Kaggle 또는 Firecrawl API 자격 증명이 제공되면, 해당 수집 커넥터를 이 로그에 추가합니다.
